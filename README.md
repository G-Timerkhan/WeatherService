# Сервис по получению метеорологических данных

Домашняя работа по Java. Реализован сервис, который получает данные о погоде из API Яндекс.Погоды.

## Функциональность:
- Выполняется GET-запрос к `https://api.weather.yandex.ru/v2/forecast` с параметрами `lat`, `lon`, `limit`.
- В заголовке запроса передается ключ `X-Yandex-Weather-Key`.
- В консоль выводится полный JSON-ответ от сервиса.
- Извлекается и выводится текущая температура из `fact.temp`.
- Рассчитывается средняя температура по прогнозу: берется `forecasts[*].parts.day.temp_avg` за первые `limit` суток, вычисляется среднее арифметическое.

## Технологии:
- Java 17
- Maven
- OkHttp (HTTP-запросы)
- Jackson (парсинг JSON)

*Внимание: в коде оставлена заглушка `"ВАШ_КЛЮЧ_ЗДЕСЬ"` вместо реального API-ключа в целях безопасности.*
